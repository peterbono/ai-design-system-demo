One GitHub App behind a switch (`BRIDGE_ONE_APP`, off by default): with it on, every page signs in with Bridge Direct, one consent covers reads and writes (no second OK for code writes), and every Install Bridge, Give Bridge access and ask-your-lead link names Bridge Direct. Someone signed in with the old app is asked once, in one plain sentence, to sign in again. docs/SIGN-IN.md and docs/HOSTED.md describe the one-app model.
