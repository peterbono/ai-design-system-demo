Studio sign-in. With Sign in with GitHub set up on the site, the designer UI has no token paste any more: the sign-in dialog, Settings and the account menu offer Sign in with GitHub only (a site without it keeps the token paste as its one way in). Signed out, every Studio page, Overview included, shows the same side nav foot: a full-width "Sign in with GitHub" button with "Read only until you sign in" under it.
