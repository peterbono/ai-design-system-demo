Figma plugin, measured only: variants pair their parts with the measure's own (an icon drawn as a vector stays shown in
every variant), a root that fills its container keeps the width the measure laid it out at (no size token needed), and a
skeleton story is no variant while a gallery only stands in for a variant no single story renders.
A boolean the stories show both ways is an axis when it draws something (Carbon Toggle `toggled`, Invalid, Read only).
A frame holding only positioned parts keeps its measured size (a switch and its knob), and an icon's fill is no longer
painted on its frame.
