Offline is calm. When there is no network, the plugin shows one neutral sentence, "You're offline. Bridge will try again when you're back.", with no details and one "Try again". The bar's action waits, and what failed runs again by itself once the connection is back. The design system keeps one name: its config name is saved with the file, so the tab bar no longer changes from the repository name to the config name after a scan. The repeated "Token values ship once the checks pass" line on Push is gone.
