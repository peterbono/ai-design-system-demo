Studio Settings is one page with three sections: Connection, Repository, Approvals. Connection opens with one sentence and one action for the GitHub state (Connect GitHub, or Change token once connected), then the Figma plugin and the MCP server as two plain rows. Repository says in one sentence which repository, branch and build it reads, shows Source at rest and folds tiers, modes, owners and previews behind counts; values share one mono style and the default mode reads "(default)" in plain text. Approvals is a compact "Who approves what" table, one row per tier with a grey label that opens Changes filtered to that tier (new ?tier= filter on In review), plus the owner override in one line. The governance prose moved to a new Library page under Use, How review works, with collapsible sections, linked from Approvals and from each pull request. The old Repository, Governance and Integrations URLs redirect to the matching section.
