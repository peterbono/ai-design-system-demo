Add a product: someone who does not own the product's account on GitHub reads, before GitHub opens, that only its owners can give Bridge access and that GitHub sends them the request, with "Copy a message for the owners". Once GitHub closes with nothing new, the dialog says the request was sent and that Bridge adds the product as soon as they approve; this browser remembers it per team, so reopening the dialog says it again, and picks the product once it arrives.
