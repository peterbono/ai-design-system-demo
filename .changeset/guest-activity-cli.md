`bridge snapshot --activity [--repo owner/name]` also writes `activity.json`, read with `GITHUB_TOKEN`, so a visitor of a team's hosted Studio who is not signed in spends no GitHub API request on Home, Branches, a branch, Review, History, suggestions and requests. `templates/bridge-data.yml` runs it on pushes, pull request, issue and comment events and every 30 minutes, and keeps one commit on the `bridge-data` branch.
