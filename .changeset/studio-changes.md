Studio Changes: one page with two views. In review lists the open pull requests most urgent first (blocked, then waiting for approval, then ready) under a Harbor opener with one status sentence and one action, the local draft as a strip, and branches without a pull request collapsed at the bottom. When GitHub cannot be read, the last list stays on screen "as of" its time, and the nav count keeps the last known number. A pull request opens in place with one sentence on its state, one primary action (open the failing run, connect GitHub, approve or merge) and collapsed sections with counts; the merge, approval and owner override rules are unchanged. History groups merged token changes by release, folds imports into one line, keeps filters behind a Filter button, and undo opens a side panel with one sentence and one primary. Color now means status only: red blocked, violet waiting for approval, green ready, grey otherwise; risk tiers are grey labels. Drafts, Branches, Reviews, Versions and Visual impact redirect to the right view. The Studio header switches to the Library, and the GitHub account moves to the bottom of the Studio nav.
