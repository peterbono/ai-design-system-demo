New tool `bridge_save_exploration` ("Save to the exploration"): Claude saves prototype code on an exploration's explore/ branch through Bridge, one commit fast-forwarded, so a designer without GitHub access (one who joined with their email, Claude on claude.ai) sees the preview update. Continue and Start now tell Claude to save this way, git push only with its own access. Core commits can carry base64 files (images, fonts).
