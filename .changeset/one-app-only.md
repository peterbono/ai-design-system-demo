One GitHub App, for good: Bridge Direct signs everyone in on every page, and the `BRIDGE_ONE_APP` switch, the older second app (`bridge-ds`, `GITHUB_APP_SUGGEST_*`), its "Allow Bridge to save your changes" second OK and its install links are gone. Someone still holding an old `bridge-ds` sign-in sees "Bridge changed how it connects to GitHub. Sign in again once to keep working." once, in the browser; the token function now accepts Bridge Direct's client ID only. Coming back from GitHub no longer loses what you were doing: after Sign in again, or Add a product's Install on GitHub, the dialog reopens at the same step with what you typed, the primary button focused and one line such as "Back from GitHub. Create Atlas now?". Nothing is sent before you click. A save stopped by an expired sign-in now says to sign in again instead of "Ask an owner" or a generic refusal.
