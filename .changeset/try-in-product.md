Try it in the product. The change detail in Studio links to the demo admin preview Vercel reported for the change, on the admin screen that changes most. Opened that way, the admin shows a Bridge toolbar: flip between the live product and this change (B), see each changed token as a before and after swatch, and jump to every screen the change alters. Token changes swap the live tokens in place; code changes move between the live admin and the preview on the same screen. Production shows nothing unless it is the live side of a code change.
