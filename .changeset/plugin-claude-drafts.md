Writing help for requests and the Push description. The request form (title and summary) and the Push Description now prefill a draft written from the detected changes, never rewritten once you type. "Copy for Claude" copies a ready prompt for Claude.ai or Claude Desktop (your own Claude plan, no key) and "Paste Claude's answer" fills the fields from the reply. Optionally, with your own Anthropic API key in Settings (Claude (optional), stored in client storage on this computer, billed to your Anthropic account), "Draft with Claude" writes the text from the change table and the before and after images. The manifest now also allows https://api.anthropic.com.
