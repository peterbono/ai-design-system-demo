The designer no longer chooses how Claude drafts. "Draft with Claude" is one button: it uses the API key when a developer saved one, and the designer's own Claude plan otherwise. The "With an API key" menu option is gone. In Settings, the Claude card says in one sentence whether drafting is ready. The setup (the MCP config for Claude Code and the Claude app, the Anthropic API key and the model) now sits under "For developers: set up Claude".
