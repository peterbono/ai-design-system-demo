Component specs: `ComponentSpec` types and helpers in the main entry, and a generator in `@bridge-ds/core/node` (`generateRepoComponentSpecs`) that derives variant axes, properties, parts and per-variant token bindings from a component's TSX and CSS modules, with a small CSS cascade. New optional `components.specs` config key (default `packages/react/component-specs.json`).
