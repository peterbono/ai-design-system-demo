A failed settings save changes nothing. The design system that is connected, its Pull and Push results (a finished Check fidelity included), and the header stay as they were. Settings no longer shows "Connected" above the error. The error gives the cause and the fix under the field it is about, for example "Bridge can't find acme/missing. Check the name, or ask an admin of the design system to give you access." Missing branch, folder and token problems get the same treatment.
