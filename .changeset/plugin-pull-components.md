Pull tab: pull components. The coded components (Button, IconButton, Badge, Tag, Input, Card) become component sets on a Components page, with variant properties from their props, a State axis, text and boolean properties, and every fill, stroke, radius, padding, gap, size and text property bound to the pulled variables. Opt-in from the Pull preview ("Also pull components"), which lists new, updated and unchanged sets and what cannot be bound. Re-pulls update sets in place, flag variants removed in code as orphans and store the signature baseline, so Push shows no request after a pull.
