You can now reach Check fidelity without going through the Pull preview. It is the secondary action at the end of a pull that built components, and on the Pull start screen of a file pulled before. Bridge reads the design system quietly, runs the comparison and scrolls to it. A component that differs always gets a designer action. "Ask Claude to fix it" shows when the stories are measured; otherwise the row offers "Copy for your developer", with each differing variant and the JSON. When the code images are missing, the screen offers "Copy for your developer" with the workflow to run, instead of a sentence with nothing to do.
