Four moments when a designer finishes something meaningful: the welcome on first open, the first pull ("Your design system is in Figma", where the bridge builds itself plank by plank), a send for review, and Check fidelity when every component matches (the Bridge mark lands next to "All N match the code"). Each moment is a Field Guide drawing from the brand that assembles once, in 900 ms, with opacity and transform only. Text and actions are usable from the first frame and the layout does not move. Nothing plays while a pull or a check runs, nothing plays on a screen that shows an error, and reduced motion shows the finished drawing.
