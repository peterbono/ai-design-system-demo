Studio reads as one app: compact page headers with no hero or lede, GitHub status only in the global header (connect button, or your login with repository, access and disconnect), a Drafts counter in the header that opens the draft as a side sheet, and the token explorer full bleed with one toolbar row (search, Filters, Modes, View, New token) and compact 40px rows. Overview starts with a KPI strip and a "Needs you" list whose status chips come from real CI, reviews and the merge gate, so a pull request with failing CI never reads "Ready". The Library is unchanged. Change titles read as text, with inline code rendered as code instead of raw backticks. Without a GitHub token, Overview and Reviews read the open list once and the live status of the 3 most recent pull requests, cached for 10 minutes per commit; other rows say "Status unknown" until you connect. New token and cell edits work without GitHub as drafts in this browser; only Propose, approve, merge and revert need a connection.
