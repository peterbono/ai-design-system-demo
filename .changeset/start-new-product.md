Add a product: "No code yet? Start a new product". Bridge starts the product's code on GitHub from the Bridge product starter with the admin's own sign-in (no "Give Bridge access" step), links it to the library, proposes it for review with the designers' copy on, then shows the way to its previews on Vercel or Cloudflare. Refusals in plain words (name taken, no permission in the account, with the ask-an-owner message). The starter's content is in `templates/product-starter`.
