Read passes for private products: a member's Studio puts a signed, 8-hour read pass on the product preview links it opens, and Bridge's read proxy lets the toolbar there read the product repositories the pass names (read only, the visitor's allow-list, origins the config names). Cloudflare Pages preview templates (`https://{branch}.<project>.pages.dev`) now count as product origins.
