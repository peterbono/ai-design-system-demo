Library edit mode reads as a mode. A sticky edit bar opens the page on the Harbor zone, full page width, with "Editing <name>" and its state (No changes yet, Draft saved, not sent, Unsaved changes, Sent for review) on the left and the actions on the right: Draft with Claude, Cancel and Send for review as the one primary. "Keep all N Claude drafts" shows only when two drafts or more wait. While editing, the page sits on a tinted desk and only editable regions are white paper, with a dashed edge and an Edit hint on hover and the focus color on focus; the live preview and the Tokens, Code and Changelog tabs say "From the code". Escape leaves a field, then asks to leave editing: Cancel confirms before discarding. On phones the bar keeps the label, Send for review and a More menu.
