Coming back from Bridge Direct's OK on GitHub no longer loses what you were doing. Before Bridge sends you to GitHub, it keeps the dialog, its step and what you typed for this tab (15 minutes, never a token). GitHub sends you back to the same page, where the dialog reopens with your values, the primary button focused and one line such as "GitHub gave the OK. Create Atlas now?". Nothing is sent before you click. Add a product (new or already built) reopens wherever you land; Start an exploration, a product's rename and removal and a new brand reopen in place; other saves get a short notice to do it again. Refused on GitHub: straight back to the page with the usual line, no error page. A write waiting for the OK now shows that line in Add a product, rename and remove instead of a generic refusal.
