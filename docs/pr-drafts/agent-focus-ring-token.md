## What changed and why

Closes #15 (example issue: "Focus ring offset is a primitive used directly in components").

- New semantic token `focus.ring.offset` in `light.tokens.json` and `dark.tokens.json`,
  aliasing `{border.width.2}` (2px). Generated as `--focus-ring-offset`.
- `Button` and `Input` `:focus-visible` now use `var(--focus-ring-offset)` instead of the primitive
  `var(--border-width-2)`.
- Value is unchanged (2px), so there is no intended visual change. The point is that focus geometry
  becomes a semantic decision the design owner can tune per theme in one place.
